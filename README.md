# Omni>_code 🎂

**ملاحظة**: هذا المشروع يُبنى كاحتفال بعيد الميلاد لتجربة أفكار متعددة في البرمجة.

## 📌 نظرة عامة
يهدف `omni>_code` إلى تجميع أدوات ومكتبات صغيرة في مستودع واحد يمكن تشغيله بسهولة كـ **one‑stop‑shop** للمهام البرمجية المتنوعة.

## ✨ المميزات
- هيكلية قابلة للتوسعة بسهولة.
- أمثلة تعليمية واضحة.
- إعداد بيئة تطوير سريعة باستخدام `npm` أو `yarn`.

## 🛠️ التثبيت
```bash
# استنساخ المستودع
git clone https://github.com/OPMOPII/My-Birthday-project.git
cd My-Birthday-project

# تثبيت الاعتمادات
npm install   # أو yarn install
```

## ▶️ التشغيل
بعد التثبيت، يمكنك تشغيل السكريبت الأساسي:
```bash
npm start   # أو yarn start
```
ستظهر لك رسالة ترحيب بمناسبة عيد الميلاد.
